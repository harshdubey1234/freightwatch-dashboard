# FreightWatch Dashboard

Freight-cost dashboard with a geographic India map, simulated 3D trucks, historical route analysis, and inspectable evidence.

Static HTML/CSS/JavaScript; no build step. Serve this folder as a static site. GitHub Pages can publish the repository root.

The truck movement is illustrative, not live GPS. The data is the supplied internship case-study dataset. This is an independent case-study prototype, not an official Freight Tiger product. See ASSET_SOURCES.md for logo, font, and map provenance.
